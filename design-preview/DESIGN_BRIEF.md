## 1. アプリ概要

- **名称**: ポケモンチャンピオンズ専用 ダメージ計算アプリ
- **目的**: 対戦中に素早くダメージ計算・パーティ管理・素早さ比較ができるモバイルWebアプリ
- **対象ユーザー**: 「ポケモンチャンピオンズ」プレイヤー（対戦勢）
- **プラットフォーム**: モバイル中心（iPhone 想定、393×852）。React + Vite + TypeScript、Capacitor で iOS 化予定
- **トーン**: 実用ツール。情報密度は高いが、洗練された見た目で「使っていて気持ちいい」こと

---

## 2. 現在のデザイン言語 — Apple「Liquid Glass（すりガラス）」

iOS の半透明すりガラス UI を踏襲。**カラフルな背景アートの上に、半透明ガラスのカードを重ねる**のが核。ダーク/ライト両対応。

### 2-1. ガラスカードの3層構造（最重要・デザインの肝）

各カードは以下の3層を重ねて「ガラス感」を出す:

1. **Tint + Blur 層**: `backdrop-filter: blur(28px) saturate(190%)` + 半透明の地色
2. **Sheen 層**: 上→下の白いハイライト `linear-gradient(180deg, rgba(255,255,255,0.32) 0%, transparent 38%, transparent 70%, rgba(255,255,255,0.04) 100%)`
3. **Rim 層**: 内側 0.5px ボーダー + 上端 1px ハイライト `inset 0 0 0 0.5px <rim>, inset 0 1px 0 rgba(255,255,255,0.22)`

- 角丸: 標準 `radius: 24`、タブバー `30`
- カードは `overflow: hidden; isolation: isolate;`

### 2-2. カラートークン（ダークテーマ）

| トークン | 値 | 用途 |
|---|---|---|
| text | `#ffffff` | 主要テキスト |

| textWeak | `rgba(255,255,255,0.4)` | 微弱テキスト |
| accentAtk | `rgba(120,210,255,0.95)` | 攻撃側アクセント（水色） |
| accentDef | `rgba(255,150,150,0.95)` | 防御側アクセント（赤） |

### 2-4. 背景アート（タブごとに切替・カラフルなグラデ）

ガラスの透過感の土台。タブ別にラジアルグラデを重ねる。

- **ダメ計（dark）**: 紫ベース `radial-gradient(120% 80% at 80% 10%, #4f3a8a, #2a2152 45%, #0e0b24)` + 水色/赤/緑の光彩 + 白い星40個
- **パーティ**: 青緑系 `#0c2d3a → #050a1a` + シアン/紫の光彩
- **素早さ**: 緑系 + スピード線エフェクト
- **履歴**: 紫オレンジ系
- **設定**: 青系
- ライトは各タブともパステル基調

### 2-5. タイポグラフィ

- 本文: `-apple-system, "Noto Sans JP", system-ui, sans-serif`
- 数値（ダメージ・実数値・SP）: `"SF Mono", "SFMono-Regular", Consolas, monospace`（**等幅で数字を強調**）
- 見出し 20px/700、本文 13px、補助 11px、極小ラベル 9〜10px
- タブ文字 13px/700、letter-spacing 0.2

### 2-6. タイプカラー（18タイプ・英語キー）

タイプチップに使用。例: Dragon `rgba(120,90,230,0.85)`/白文字、Ground `rgba(200,160,90,0.9)`/濃茶、Steel `rgba(180,190,210,0.85)`、Fire `rgba(255,120,60,0.85)`/白、Water `rgba(80,160,255,0.85)`/白、Electric `rgba(255,210,0,0.85)`、Fairy `rgba(255,170,210,0.9)`。

## 3. 画面インベントリ（フローティングタブバーで5画面切替）

下部に**浮いた角丸ガラスのタブバー**（左右18px・下26px・高さ60px）。アクティブタブは幅が1.4倍に広がりラベルが出る。

| タブ | アイコン | 内容 |
|---|---|---|
| **ダメ計** | 電卓 | メイン。攻撃→防御の対面、技選択、ダメージ結果、SP振りスライダー |
| **パーティ** | 人2人 | 手持ち6体管理、ボックス、各個体の育成 |
| **素早さ** | 稲妻 | 自分↔相手の素早さ実数値比較 |
| **履歴** | 時計矢印 | 過去のダメ計・対戦履歴（件数バッジ付き） |
| **設定** | 歯車 | ダーク/ライト切替など |

### ダメ計画面の構成（最重要）
1. 見出し「ダメージ計算」
2. **対面カード**: 攻撃ポケモン　▶　防御ポケモン（各カードに名前・タイプチップ）
3. **技選択**: 技名・タイプ・威力・分類（物理/特殊）
4. **結果カード**: ダメージ範囲（185–218）・割合（92.0%）・判定（確定2発/乱数1発）・横バー（16段階乱数を反映）
5. **SP振りスライダー**: 各ステータス 0〜32SP。丸いつまみ + 水色グラデのトラック + 実数値表示 + 0/MAX ボタン

### モーダル類（共通部品）
- ポケモン選択モーダル、技選択モーダル、性格選択モーダル（いずれもガラス調・全画面下からスライドイン）

## 4. 主要コンポーネント仕様

- **Glass**: 上記3層のガラスカード。`padding=16, radius=24` がデフォルト
- **SpSlider**: SP振りスライダー。ラベル+実数値+「0」「MAX」ボタン、4px トラックに水色グラデ `linear-gradient(90deg, #5AC8FA, #74E0FF)`（振ると `box-shadow: 0 0 8px rgba(90,200,250,0.5)` で発光）、16px の白い丸つまみ
- **TabBar**: 浮遊ガラス。アクティブは `flex:1.4` + 白いハイライト背景 + ラベル表示。非アクティブはアイコンのみ
- **タイプチップ**: 角丸6px、タイプ色背景、10px/700

## 5. 検討中のリニューアル方向（付録・どれかに編集したい場合の指針）

現状はガラス調。以下いずれかへ「デザイン言語を一新」する案を検討中。**Claude Design で試すならこの3方向のどれかを指定**:

### 案A: クール / ミニマル（推奨）
- 黒基調 `#0a0a0b` / カード `#161618` / 枠 `#262629`、**フラット（blur・sheen なし）**
- アクセントは青 `#3b82f6` の1色のみ。余白多め
- ダメ計ツールとして最も可読性が高く高速。背景アートは廃止し単色

### 案B: ポップ / カラフル
- パステルグラデ背景、丸ゴシック `"M PLUS Rounded 1c"`、角丸大きめ22px、白カード+ピンク影
- タイプ別色チップを主役に、ダメージバーはピンク→オレンジのグラデ
- アクセント: ピンク `#ff5fa2` / オレンジ `#ffaa5f`

### 案C: レトロ / ドット絵
- 初代ポケモン風。ドットフォント `"DotGothic16"`、太い白枠線3px + ドロップシャドウ `4px 4px 0`、角丸なし
- 濃紺背景 `#101840`、原色（赤・黄・緑）、ダメージバーはドット/ストライプ
- 見出しは黄色+赤シャドウ

## 7. 制約・補足

- モバイル前提。タッチターゲット最小 44×44px
- 情報密度が高い（1画面に対面+技+結果+複数スライダー）ため、可読性を最優先
- 等幅数字は崩さない（ダメージ・実数値の比較に必須）
- 永続化は localStorage、データは外部 fetch（デザインには無関係）
- 同梱の `preview.html` に案A/B/Cの簡易ビジュアルあり（ブラウザで切替確認可能）
