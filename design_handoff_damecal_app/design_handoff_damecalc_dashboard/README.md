# Handoff: ダメ計アプリ リニューアル — 案⑤「分析ツール / ダッシュボード」

## Overview
ポケモンチャンピオンズ向けダメージ計算モバイルWebアプリ（iPhone 393×852）のメイン「ダメ計」画面のリニューアルデザインです。現行の Apple「Liquid Glass」調（半透明ガラス＋カラフルな背景アート）から、**プロの対戦分析ツール風**のフラットで精密な見た目へ刷新します。背景アートを廃し、薄いグリッド線・等幅フォント・シアン1色のアクセントで、情報密度を保ったまま高速に読める設計です。

## About the Design Files
このバンドル内の HTML ファイルは **HTML で作られたデザイン参照（プロトタイプ）** です。意図した見た目・構造・配色・寸法を示すものであり、そのまま本番コードにコピーするものではありません。

タスクは、これらの HTML デザインを **対象コードベースの既存環境（このアプリの場合 React + Vite + TypeScript、Capacitor で iOS 化）の確立したパターン・ライブラリで再現すること** です。HTML/CSS をそのまま移植するのではなく、既存のコンポーネント構成・状態管理・スタイリング手法に沿って実装してください。

> 注: 本デザインは現行アプリの「デザイン言語の一新」です。既存の `Glass` / `SpSlider` / `TabBar` などのコンポーネントは構造（props・レイアウト・状態）を流用しつつ、**見た目のスタイルだけ**を本仕様に差し替える形が望ましいです。ロジック（ダメージ計算・localStorage 永続化・データ取得）はデザイン非依存なので変更不要です。

## Fidelity
**High-fidelity (hifi)** です。最終的な配色・タイポgrafィ・余白・寸法を確定値で記載しています。下記トークンに従ってピクセル単位で再現してください。ライトテーマを先に実装し、ダークテーマは本仕様の方針（§ダークテーマ指針）に沿って後追いで対応します。

## Screens / Views

### ダメ計（メイン画面）
- **Name**: Damage Calc（ダメ計タブ）
- **Purpose**: 対戦中に攻撃ポケモン→防御ポケモンの対面で、選択技のダメージ範囲・割合・確定数を即座に確認し、防御側の努力値(SP)を振って耐久ラインを調整する。
- **Layout**: 縦1カラム。画面全体は薄いグリッド線の背景。上から順に①ステータスバー ②ヘッダー ③対面グリッド ④技行 ⑤結果パネル ⑥SPスライダー群、最下部に固定タブバー。
  - 画面: `393 × 852`、角丸 `46px`（デバイス枠の表現。実機では不要）
  - コンテンツ左右パディング: `20px`、各ブロック間 `margin-top: 12〜16px`
  - 背景: `#eceef0` ＋ グリッド線 `#dde1e4` 1px、セル `26px × 26px`
    - CSS: `background-image: linear-gradient(#dde1e4 1px, transparent 1px), linear-gradient(90deg, #dde1e4 1px, transparent 1px); background-size: 26px 26px;`

#### Components

**1. ステータスバー**
- 左に時刻 `21:30`（DM Mono / 13px / 500 / `#15202b`）、右にインジケータ。実機では OS ステータスバーに置換。
- padding: `14px 30px 0`

**2. ヘッダー行**
- 左: ラベル `DAMAGE_CALC` — Hanken Grotesk / 13px / 800 / `#15202b` / letter-spacing `0.04em`
- 右: バッジ `SINGLES` — 10px / `#fff` / 背景 `#0a96b8`（アクセント）/ padding `3px 8px` / radius `3px`

**3. 対面グリッド（matchup）**
- `display: grid; grid-template-columns: 1fr auto 1fr;`、中央列は 1px の縦罫 `#c6ccd1`
- カード: 背景 `#fff` / border `1px solid #c6ccd1` / radius `6px` / overflow hidden、各セル padding `12px 13px`
- 左（攻撃）: ラベル `ATK //` 9px `#0a96b8` letter-spacing `0.08em` → 名前 `ガブリアス` Hanken 16px/800 `#15202b`（margin-top 5px）→ タイプチップ
- 右（防御）: ラベル `// DEF` 9px `#8a949c`（右寄せ）→ 名前 `パオジアン` → タイプチップ（右寄せ）
- **タイプチップ**: 9px/700 / padding `2px 6px` / radius `3px`。配色は §タイプカラー参照（DRAGON, GROUND / DARK, ICE）

**4. 技行（move）**
- border `1px solid #c6ccd1` / 背景 `#fff` / radius `6px` / padding `10px 13px` / flex space-between
- 左: タイプチップ `GND`（GROUND色）＋ 技名 `じしん` Hanken 15px/800 `#15202b`
- 右: `PWR 100 · PHYS` DM Mono 12px `#5a646c`

**5. 結果パネル（result）— アクセント枠**
- border `1px solid #0a96b8`（シアン強調）/ 背景 `#fff` / radius `6px`
- 上段: 2分割（縦罫 `#d8dde1`、下罫 `#d8dde1`）
  - 左 `DMG_RANGE`: ラベル 9px `#8a949c` → 値 `185–218` DM Mono 26px/500 `#15202b`（ダッシュは en dash `–`）
  - 右 `PERCENT`: ラベル 9px `#8a949c` → 値 `92.0%` DM Mono 26px/500 `#0a96b8`
- 下段: padding `12px 13px`
  - 行ヘッダ: 左 `ROLL · 16` 9px `#8a949c` / 右 確定数バッジ `確定2発` Hanken 12px/800 `#15202b` 背景 `#e3f4f8` padding `2px 9px` radius `3px`
  - **16分割乱数バー**: 16個の `flex:1` セル、`gap:2px`、高さ `9px`。乱数ヒット数だけ `#0a96b8`、残りは `#cdd3d8`（この例は12/16が点灯）

**6. SPスライダー群（SpSlider）**
- セクションラベル `DEF_EV //` 9px `#8a949c` letter-spacing `0.08em`
- 各行: 上に [ステータス名（Hanken 12px/800 `#15202b`）＋ SP値（DM Mono 11px/400 `#8a949c`）] と [実数値（DM Mono 14px/500 `#0a96b8`、右寄せ）]
- トラック行: 左ラベル `0`・右ラベル `MAX`（各 10px `#aab2b8`）を挟む
  - トラック: 高さ `4px` / 背景 `#d3d9dd` / radius `2px`
  - フィル: `#0a96b8` / radius `2px`（width = SP割合）
  - つまみ: `12×12px` / 円 / 背景 `#fff` / border `2px solid #0a96b8` / 中央配置（`transform: translate(-50%,-50%)`）
- この例: HP 20SP→191（62%）、DEF 12SP→130（38%）。実際は H/A/B/C/D/S 各 0〜32SP。

**7. タブバー（TabBar）— 5タブ固定フッター**
- 上罫 `1px solid #c6ccd1` / 背景 `#fbfcfc` / padding `12px 24px 28px`（下は端末セーフエリア分）/ flex space-between
- アクティブ（ダメ計）: アイコン＋ラベル縦並び、色 `#0a96b8`、ラベル `ダメ計` Hanken 9px/800
- 非アクティブ: アイコンのみ、stroke `#a7afb5`
- アイコン: 21px、stroke-width 2 のラインアイコン（電卓 / 人2人 / 稲妻 / 時計 / スライダー）
- ※現行仕様の「アクティブが flex:1.4 で広がる浮遊ガラスタブ」ではなく、本案は**フラットな固定フッター**。アクティブはアイコン色＋ラベル表示で示す。

## Interactions & Behavior
- **対面カードのタップ**: ポケモン選択モーダル（全画面下からスライドイン）を開く。攻撃/防御それぞれ。
- **技行のタップ**: 技選択モーダルを開く。選択後、結果パネルと乱数バーが即時再計算。
- **SPスライダーのドラッグ**: 1SP単位（0〜32）で増減。ドラッグ中はリアルタイムに実数値・結果パネル・乱数バーが更新。トラックのタップでその位置へジャンプ。
- **0 / MAX**: 現行仕様にあるクイックボタン（0振り / 252振り相当の最大）。本案でも左右ラベル位置に小さなタップターゲットとして配置可（最小44×44px確保）。
- **タブ切替**: 5画面（ダメ計/パーティ/素早さ/履歴/設定）を即時切替。アクティブ表示は色＋ラベル。
- **アニメーション**: 結果数値・バーの更新は短いトランジション（推奨 120〜160ms / ease-out）。誇張した動きは不要（実用ツールとして即応性優先）。
- **乱数バー**: 16段階の乱数のうち、対象を1発で倒せる/耐えるラインを色分けで可視化（点灯 = 該当ロール）。

## State Management
- `attacker` / `defender`: 選択ポケモン（種族・タイプ・実数値・性格・特性・持ち物など）
- `move`: 選択技（名前・タイプ・威力・分類 物理/特殊）
- `defenderEVs`: { hp, atk, def, spa, spd, spe } 各 0〜32（SP）。スライダーで更新→実数値を再計算
- `result`: 計算結果 { min, max, percentMin, percentMax, koLabel('確定2発'等), rolls[16] }
- データ取得（種族値・技データ等）は外部 fetch、永続化は localStorage（**デザイン非依存・既存ロジック流用**）

### Typography
| 役割 | フォント | サイズ / ウェイト |
|---|---|---|
| UIラベル・見出し・名前 | Hanken Grotesk（日本語は Noto Sans JP） | 9〜16px / 800 |
| 数値（ダメージ・実数値・%・SP・PWR） | DM Mono（等幅・**必須**） | 11〜26px / 400〜500 |
| 本文補助 | DM Mono | 12px / 400 |
- 大見出し（DAMAGE_CALC等）は letter-spacing `0.04em`、極小ラベルは `0.06〜0.08em`、英字は基本大文字。
- ※等幅数字は崩さないこと（ダメージ・実数値の桁揃え比較に必須）。

### Spacing
- コンテンツ左右パディング `20px`、ブロック間 `12〜16px`、カード内 `10〜13px`
- タッチターゲット最小 `44×44px`

### Border radius
- カード/パネル/技行 `6px`、チップ `3px`、バッジ `3px`、スライダーつまみ 円（`50%`）、トラック `2px`

### その他
- 影は基本なし（フラット）。区切りは 1px の罫線で表現。
- グリッド線背景がこの案のアイデンティティ。カード下にうっすら覗く程度の薄さを保つ。

## ダークテーマ指針（後追い）
背景を濃紺グレー（例 `#15181c`）＋グリッド線を `#23272d` 程度に。カードは `#1c2026`、枠 `#2c333a`、アクセント `#0a96b8` は維持（やや明るめ `#19b6d8` でも可）、主テキスト `#e8edf1`。乱数バー点灯はアクセント、非点灯 `#343b42`。

## Assets
- 画像アセットなし。タブバー・技分類のアイコンは inline SVG ラインアイコン（stroke-width 2）。実装では既存のアイコンライブラリ（例: Lucide / SF Symbols 等、コードベースの標準）に置換推奨。
- ポケモン画像・タイプアイコンを使う場合は別途素材が必要（本デザインには未使用）。
